# Lab B04 — Un même contenu, trois groupements Gestalt

> **Module associé :** [`modules/b04-gestalt.md`](../../modules/b04-gestalt.md)
> **Forme :** Zéro — construire trois versions distinctes d'un même écran.
> **Outil :** Figma.

## Lire avant

Relire précisément, pas tout le module :
- §2.1-2.3 (proximité, similarité, continuité) — les trois lois utilisées dans ce lab.
- §2.7 "Quand deux lois entrent en conflit" — pour éviter de mélanger les lois dans une même
  version sans le vouloir.
- §3 "Exemple B" — c'est le raisonnement attendu, pas le corrigé exact.

Ne pas chercher à rendre les trois versions "également belles" — l'objectif est de prouver
qu'on contrôle CHAQUE loi isolément, pas de produire trois maquettes abouties.

## Brief

Prendre une même liste de contenu réel de TribuZen (ex. les routines de plusieurs enfants
sur une journée) et produire **trois versions**, même contenu textuel exact, qui groupent
visuellement cette liste de trois façons différentes :

1. **Version par proximité seule** : rapprocher spatialement les éléments d'un même groupe
   (ex. par enfant), sans aucune couleur distinctive entre les groupes.
2. **Version par similarité seule** : disperser les éléments sur l'écran sans les rapprocher,
   mais donner à chaque groupe une couleur d'accent cohérente et distincte.
3. **Version par continuité** : aligner les éléments d'un même groupe le long d'une ligne ou
   d'une courbe continue (ex. une frise horaire), sans rapprochement ni couleur distinctive
   déterminants.

## Livrable attendu

- Un fichier Figma avec les 3 frames nommées explicitement (`01-proximite`,
  `02-similarite`, `03-continuite`).
- Une note texte, pour chaque version, qui explique ce qu'elle communique de différent au
  lecteur (ex. "la version 1 dit : ces routines sont ensemble ici ; la version 2 dit : ces
  routines appartiennent à la même catégorie partout sur l'écran").

## Rubrique de vérification

**Rubrique objective :**
- Les 3 frames existent, nommées, avec le même contenu textuel exact dans les 3.
- La version 1 ne contient AUCUNE couleur distinctive entre groupes — seul l'espacement
  sépare les groupes.
- La version 2 ne contient AUCUN rapprochement spatial entre les éléments d'un même groupe
  — seule la couleur les relie.
- La version 3 aligne les éléments d'un groupe sur une trajectoire continue identifiable
  (ligne, courbe, frise), pas un alignement générique en grille.
- Chaque note explique la loi appliquée et ce qu'elle communique — pas de justification
  "parce que c'est plus clair" sans nommer le mécanisme.

**Revue qualitative :** le brief demandait de prouver un contrôle conscient de chaque loi —
la question n'est jamais "quelle version est la plus belle" mais "un tiers qui regarde
chaque version sans explication perçoit-il le regroupement voulu, et seulement celui-là,
sans qu'un autre mécanisme involontaire (une proximité ou une similarité non maîtrisée)
brouille la lecture".

## Variante J+30 (fading)

Reprendre la version 2 (par similarité) et y introduire délibérément un conflit : rapprocher
spatialement deux éléments de groupes DIFFÉRENTS (proximité qui pousse à les lier) tout en
gardant leurs couleurs distinctes (similarité qui pousse à les séparer). Documenter lequel
des deux signaux l'emporte à l'œil, puis corriger en renforçant consciemment le signal voulu
(augmenter l'espacement, ou unifier davantage la couleur) — preuve que le conflit entre lois
se résout par un choix actif, pas par hasard.
